# 使用说明

## 推荐方式：在 version control 目录中设置虚拟环境

### 第一步：设置虚拟环境

**Windows 用户（在 PowerShell 中）：**

```powershell
cd "version control"
.\setup_env.bat
```

**或者手动设置：**

```powershell
cd "version control"
python -m venv venv
.\venv\Scripts\Activate.ps1  # PowerShell
# 或者
.\venv\Scripts\activate.bat  # CMD

pip install -r deploy_requirements.txt
```

### 第二步：配置服务器信息

```powershell
# 复制配置文件
copy deploy_config.example.json deploy_config.json

# 编辑 deploy_config.json，填入服务器信息
notepad deploy_config.json
```

配置文件格式：
```json
{
  "server_host": "47.108.224.128",
  "server_port": 22,
  "server_username": "admin",
  "server_password": "你的密码",
  "server_path": "/home/admin/eye/media/exehtml"
}
```

### 第三步：部署

#### 方式一：打包并部署最新版本（需要先构建）

**使用 npm 命令（推荐）：**

```powershell
# 从项目根目录运行
npm run deploy
```

这会自动：
1. 运行 `npm run build` 构建项目
2. 创建新版本
3. 提示选择部署到 v1（稳定版）或 v2（测试版）
4. 部署到服务器

**或使用交互式脚本：**

```powershell
cd "version control"
.\deploy_interactive.bat
```

#### 方式二：从历史版本中选择并部署（不需要重新构建）

**使用 npm 命令（推荐）：**

```powershell
# 从项目根目录运行
npm run deploy:select
```

**或直接运行脚本：**

```powershell
cd "version control"
.\deploy_select.bat
```

这会：
1. 显示所有历史版本列表
2. 让你选择要部署的版本
3. 选择部署到 v1（稳定版）或 v2（测试版）
4. 直接部署选中的版本到服务器

#### 方式三：命令行直接部署指定版本

```powershell
# 部署指定版本到 v1（稳定版）
cd "version control"
venv\Scripts\activate.bat
python deploy_v2.py --version 20260111-1 --version-type v1

# 部署指定版本到 v2（测试版）
python deploy_v2.py --version 20260111-1 --version-type v2
```

## 完整使用流程示例

```powershell
# 1. 首次设置（只需要做一次）
cd "version control"
.\setup_env.bat

# 2. 配置服务器信息（只需要做一次）
copy deploy_config.example.json deploy_config.json
notepad deploy_config.json  # 编辑并保存

# 3. 后续每次部署
# 方法A：打包并部署最新版本（推荐）
cd ..
npm run deploy

# 方法B：从历史版本中选择并部署（不需要重新构建）
cd ..
npm run deploy:select

# 方法C：命令行直接部署指定版本
cd "version control"
venv\Scripts\activate.bat
python deploy_v2.py --version 20260111-1 --version-type v1
```

## 部署方式说明

### 部署目标目录

- **v1（稳定版）**: `/home/admin/eye/media/exehtml/v1`
- **v2（测试版）**: `/home/admin/eye/media/exehtml/v2`

### 部署命令对比

| 命令 | 说明 | 是否需要构建 |
|------|------|-------------|
| `npm run deploy` | 打包最新代码并部署 | ✅ 需要 |
| `npm run deploy:select` | 从历史版本中选择并部署 | ❌ 不需要 |
| `npm run deploy:interactive` | 交互式部署（可选择打包或选择历史版本） | 可选 |

### 命令行参数

```powershell
# 查看所有可用参数
cd "version control"
venv\Scripts\activate.bat
python deploy_v2.py --help

# 常用参数：
# --version: 指定版本名称（如：20260111-1）
# --version-type: 部署类型（v1 或 v2）
# --description: 部署描述
```

## 注意事项

⚠️ **重要提示**：
1. 虚拟环境只需要设置一次
2. 使用 `npm run deploy` 或批处理脚本会自动激活虚拟环境，无需手动激活
3. 配置文件 `deploy_config.json` 包含敏感信息，不要提交到 Git
4. 部署前确保服务器连接正常
5. 从历史版本部署时，确保该版本文件存在于 `versions/` 目录中
