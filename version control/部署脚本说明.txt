========================================
一键部署脚本 - 功能说明
========================================

✅ 已完成功能
========================================

1. ✅ 一键上传功能
   - 使用SFTP连接服务器
   - 自动上传dist目录文件到服务器指定位置

2. ✅ 文件部署规则
   ✓ dist/index.html → /home/admin/eye/media/exehtml/index.html
   ✓ dist/assets/* → /home/admin/eye/media/exehtml/assets/*（递归上传）
   ✓ dist/static/* → /home/admin/eye/media/exehtml/static/*（递归上传）
   ✓ dist/templates/* → /home/admin/eye/media/exehtml/templates/*（如果存在）

3. ✅ 自动覆盖
   - 所有同名文件会自动覆盖

4. ✅ 部署日志
   - 在服务器上自动创建/更新 deploy_log.json
   - 记录部署时间、文件数量、文件列表
   - 保留最近50次部署记录
   - 日志位置: /home/admin/eye/media/exehtml/deploy_log.json

5. ✅ 使用方式
   - 命令行: python "version control/deploy.py"
   - npm脚本: npm run deploy 或 npm run build:deploy

========================================
快速使用步骤
========================================

1. 安装依赖
   pip install paramiko

2. 配置服务器信息
   - 复制 deploy_config.example.json 为 deploy_config.json
   - 编辑配置文件，填入服务器信息

3. 构建项目
   npm run build

4. 一键部署
   npm run deploy

   或者：构建+部署（一键完成）
   npm run build:deploy

========================================
配置文件说明
========================================

文件位置: "version control/deploy_config.json"

配置项:
{
  "server_host": "47.108.224.128",      // 服务器地址
  "server_port": 22,                     // SSH端口
  "server_username": "admin",            // 用户名
  "server_password": "your-password",    // 密码
  "server_path": "/home/admin/eye/media/exehtml"  // 目标路径
}

========================================
注意事项
========================================

⚠️ 部署会覆盖服务器上的同名文件，请确保已备份重要文件
⚠️ 确保服务器有足够的磁盘空间
⚠️ 部署过程中请勿中断
⚠️ 建议将 deploy_config.json 添加到 .gitignore 避免密码泄露

========================================
查看部署日志
========================================

使用 WinSCP 或 SSH 连接到服务器，查看文件:
/home/admin/eye/media/exehtml/deploy_log.json

日志格式: JSON数组，包含最近50次部署记录
每一条记录包含: 时间戳、描述、文件数量、文件列表
