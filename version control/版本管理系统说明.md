# 版本管理系统使用说明

## 系统概述

新的版本管理系统实现了完整的版本控制流程：

1. ✅ **自动版本创建**：npm build 完成后自动创建版本文件夹（如：20260110-1）
2. ✅ **版本文件夹管理**：每个版本包含完整的打包产物
3. ✅ **版本选择部署**：部署时选择要使用的版本文件夹
4. ✅ **本地日志记录**：所有部署日志记录在本地 `versions/deploy_log.json`

## 目录结构

```
项目根目录/
├── dist/                    # 构建输出（临时）
├── versions/                # 版本存储目录
│   ├── 20260110-1/         # 版本文件夹（日期-序列号）
│   │   ├── index.html
│   │   ├── assets/
│   │   └── static/
│   ├── 20260110-2/         # 同一天的第2个版本
│   ├── version_log.json    # 版本列表日志
│   └── deploy_log.json     # 部署日志
└── version control/
    ├── version_builder.py   # 版本构建器
    ├── deploy_v2.py         # 版本部署脚本
    └── version_manager_cli.py  # 版本管理CLI工具
```

## 使用流程

### 第一步：构建并创建版本

运行构建命令，系统会自动：
1. 执行 `npm run build` 生成 `dist` 目录
2. 执行 `postbuild` 脚本，将 `dist` 内容复制到版本文件夹（如：`20260110-1`）

```bash
npm run build:version
```

或者直接：

```bash
npm run build
```

构建完成后，会在 `versions` 目录下创建新的版本文件夹，例如：
- `versions/20260110-1/` - 2026年1月10日的第1个版本
- `versions/20260110-2/` - 2026年1月10日的第2个版本

### 第二步：查看可用版本

```bash
# 列出版本
python "version control/version_manager_cli.py" list

# 或者使用部署工具列出版本
cd "version control"
.\deploy.bat --list
```

### 第三步：部署指定版本

#### 方式一：部署最新版本（推荐）

```bash
cd "version control"
.\deploy.bat
```

#### 方式二：部署指定版本

```bash
cd "version control"
.\deploy.bat --version 20260110-1 --description "修复登录bug"
```

#### 方式三：使用 npm 脚本

```bash
npm run deploy-version -- --version 20260110-1
```

## 版本管理命令

### 查看版本列表

```bash
python "version control/version_manager_cli.py" list
```

### 查看版本详情

```bash
python "version control/version_manager_cli.py" show 20260110-1
```

### 删除版本

```bash
# 删除版本（保留文件）
python "version control/version_manager_cli.py" delete 20260110-1 --keep-files

# 删除版本（删除文件）
python "version control/version_manager_cli.py" delete 20260110-1
```

## 部署命令参数

```bash
python "version control/deploy_v2.py" [选项]

选项:
  --version VERSION    要部署的版本名称（格式：YYYYMMDD-N）
                       如果不指定则使用最新版本
  --config FILE        配置文件路径（默认：deploy_config.json）
  --description TEXT   部署描述
  --list               列出所有可用版本
```

## 版本命名规则

版本文件夹命名格式：`YYYYMMDD-N`

- **YYYYMMDD**：日期（年-月-日）
- **N**：该日期的序列号（从1开始）

示例：
- `20260110-1`：2026年1月10日的第1个版本
- `20260110-2`：2026年1月10日的第2个版本
- `20260111-1`：2026年1月11日的第1个版本

## 部署流程详解

1. **选择版本**：如果未指定 `--version`，使用最新版本
2. **验证版本**：检查版本文件夹是否存在
3. **连接服务器**：使用SFTP连接到服务器
4. **上传文件**：
   - `index.html` → `/home/admin/eye/media/exehtml/index.html`
   - `assets/*` → `/home/admin/eye/media/exehtml/assets/*`
   - `static/*` → `/home/admin/eye/media/exehtml/static/*`
5. **更新版本状态**：标记版本为"deployed"
6. **记录日志**：在本地 `versions/deploy_log.json` 记录部署信息

## 完整工作流程示例

```bash
# 1. 构建并创建版本
npm run build
# 输出: 已创建版本 20260110-1

# 2. 查看版本列表
python "version control/version_manager_cli.py" list
# 显示所有版本

# 3. 部署最新版本
cd "version control"
.\deploy.bat --description "修复登录bug"

# 4. 查看部署日志
# 打开 versions/deploy_log.json 查看部署记录

# 5. 如果需要回滚，部署之前的版本
.\deploy.bat --version 20260109-3 --description "回滚到稳定版本"
```

## 注意事项

⚠️ **重要提示**：

1. **版本文件夹不会自动删除**：旧的版本文件夹会一直保留，需要手动清理
2. **日志保留数量**：版本日志保留最近100个版本，部署日志保留最近100次部署
3. **dist目录**：构建完成后，`dist` 目录仍然存在，但部署时使用的是版本文件夹中的内容
4. **版本选择**：如果不指定 `--version`，默认使用最新创建的版本
5. **部署覆盖**：部署会覆盖服务器上的同名文件

## 常见问题

### Q: 如何手动创建版本？

A: 可以手动运行版本构建器：

```bash
python "version control/version_builder.py" --dist ./dist --description "手动创建版本"
```

### Q: 如何清理旧版本？

A: 使用版本管理工具删除：

```bash
python "version control/version_manager_cli.py" delete 20260109-1
```

### Q: 版本文件夹占用空间太大怎么办？

A: 可以定期清理旧版本文件夹，或者修改 `version_builder.py` 中的保留数量限制。

### Q: 如何查看某个版本的部署历史？

A: 查看 `versions/deploy_log.json`，搜索对应的 `version_name`。
