# 一键部署快速开始指南

## 第一步：设置虚拟环境（推荐）

在 `version control` 目录中创建独立的虚拟环境，隔离部署脚本的依赖。

### Windows 用户：

```bash
cd "version control"
setup_env.bat
```

或者手动创建：

```bash
cd "version control"
python -m venv venv
venv\Scripts\activate.bat
pip install -r deploy_requirements.txt
```

### Linux/Mac 用户：

```bash
cd "version control"
chmod +x setup_env.sh
./setup_env.sh
```

或者手动创建：

```bash
cd "version control"
python3 -m venv venv
source venv/bin/activate
pip install -r deploy_requirements.txt
```

## 第二步：配置服务器信息

1. 复制配置文件：
```bash
cd "version control"
copy deploy_config.example.json deploy_config.json
```

2. 编辑 `deploy_config.json`，填入你的服务器信息：
```json
{
  "server_host": "47.108.224.128",
  "server_port": 22,
  "server_username": "admin",
  "server_password": "你的密码",
  "server_path": "/home/admin/eye/media/exehtml"
}
```

⚠️ **重要**: 修改密码后保存文件

## 第三步：一键部署

### 方法一：使用批处理脚本（Windows，推荐）

```bash
# 进入 version control 目录
cd "version control"

# 一键部署（会自动激活虚拟环境）
deploy.bat

# 或者指定 dist 目录
deploy.bat --dist ..\dist
```

### 方法二：使用 Shell 脚本（Linux/Mac，推荐）

```bash
# 进入 version control 目录
cd "version control"

# 添加执行权限（首次使用）
chmod +x deploy.sh

# 一键部署（会自动激活虚拟环境）
./deploy.sh

# 或者指定 dist 目录
./deploy.sh --dist ../dist
```

### 方法三：使用 npm 命令（需要先激活虚拟环境）

```bash
# 先激活虚拟环境
cd "version control"
venv\Scripts\activate.bat  # Windows
# 或
source venv/bin/activate   # Linux/Mac

# 回到项目根目录，然后执行
cd ..
npm run build      # 先构建
npm run deploy     # 再部署（使用虚拟环境中的Python）
```

### 方法四：手动使用 Python 脚本

```bash
# 先激活虚拟环境
cd "version control"
venv\Scripts\activate.bat  # Windows
# 或
source venv/bin/activate   # Linux/Mac

# 运行部署脚本
python deploy.py

# 或者指定 dist 目录
python deploy.py --dist ../dist
```

## 常见问题

**Q: 提示配置文件不存在？**  
A: 确保已创建 `deploy_config.json` 文件

**Q: 提示连接失败？**  
A: 检查服务器地址、用户名、密码是否正确，确保网络连接正常

**Q: 部署成功后如何验证？**  
A: 在浏览器访问你的网站，确认更新已生效
