# 版本管理系统 - 快速使用指南

## 🚀 三步开始使用

### 第一步：构建并创建版本

```bash
npm run build
```

会自动：
- ✅ 构建项目到 `dist` 目录
- ✅ 创建版本文件夹（如：`versions/20260110-1/`）
- ✅ 将 dist 内容复制到版本文件夹

### 第二步：查看可用版本

```bash
python "version control/version_manager_cli.py" list
```

### 第三步：部署版本

```bash
cd "version control"
.\deploy.bat
```

或者部署指定版本：

```bash
.\deploy.bat --version 20260110-1 --description "修复bug"
```

## 📝 版本命名规则

格式：`YYYYMMDD-N`

- `20260110-1` = 2026年1月10日的第1个版本
- `20260110-2` = 2026年1月10日的第2个版本

## 📂 文件位置

- **版本文件夹**: `versions/20260110-1/`
- **版本列表日志**: `versions/version_log.json`
- **部署日志**: `versions/deploy_log.json`

## 🔧 常用命令

```bash
# 列出版本
python "version control/version_manager_cli.py" list

# 查看版本详情
python "version control/version_manager_cli.py" show 20260110-1

# 删除版本
python "version control/version_manager_cli.py" delete 20260110-1

# 部署最新版本
cd "version control" && .\deploy.bat

# 部署指定版本
cd "version control" && .\deploy.bat --version 20260110-1
```

## ✅ 完成！

现在你的工作流程是：

1. `npm run build` → 自动创建版本文件夹
2. 选择版本 → 使用 `--version` 参数
3. 部署 → `.\deploy.bat`
4. 查看日志 → `versions/deploy_log.json`

所有日志都在本地！🎉
