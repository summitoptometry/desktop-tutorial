# 虚拟环境设置说明

## 为什么使用虚拟环境？

在 `version control` 目录中创建独立的虚拟环境可以：
- ✅ 隔离部署脚本的依赖，不影响系统Python环境
- ✅ 确保依赖版本一致性
- ✅ 方便管理和维护
- ✅ 避免与其他项目冲突

## 快速设置

### Windows 用户

1. **打开 PowerShell 或 CMD**
2. **进入 version control 目录**：
   ```powershell
   cd "version control"
   ```
3. **运行设置脚本**：
   ```powershell
   .\setup_env.bat
   ```

   脚本会自动：
   - 创建虚拟环境（如果不存在）
   - 激活虚拟环境
   - 安装依赖（paramiko）

### Linux/Mac 用户

1. **打开终端**
2. **进入 version control 目录**：
   ```bash
   cd "version control"
   ```
3. **添加执行权限并运行设置脚本**：
   ```bash
   chmod +x setup_env.sh
   ./setup_env.sh
   ```

   脚本会自动：
   - 创建虚拟环境（如果不存在）
   - 激活虚拟环境
   - 安装依赖（paramiko）

## 手动设置

### Windows

```bash
cd "version control"

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate.bat

# 升级 pip
python -m pip install --upgrade pip

# 安装依赖
pip install -r deploy_requirements.txt
```

### Linux/Mac

```bash
cd "version control"

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r deploy_requirements.txt
```

## 验证安装

激活虚拟环境后，运行以下命令验证：

```bash
python --version
pip list
```

你应该能看到 `paramiko` 包已安装。

## 使用虚拟环境

### 激活虚拟环境

**Windows:**
```bash
cd "version control"
venv\Scripts\activate.bat
```

**Linux/Mac:**
```bash
cd "version control"
source venv/bin/activate
```

激活后，命令提示符前会显示 `(venv)`。

### 运行部署脚本

激活虚拟环境后，可以直接运行：

```bash
# 在虚拟环境中运行
python deploy.py

# 或使用快捷脚本（自动激活虚拟环境）
deploy.bat        # Windows
./deploy.sh       # Linux/Mac
```

### 退出虚拟环境

```bash
deactivate
```

## 目录结构

设置完成后，`version control` 目录结构如下：

```
version control/
├── venv/                    # 虚拟环境目录（自动生成）
│   ├── Scripts/            # Windows 可执行文件
│   ├── bin/                # Linux/Mac 可执行文件
│   └── lib/                # Python 库
├── deploy.py               # 部署脚本
├── deploy_config.json      # 配置文件（需手动创建）
├── deploy_requirements.txt # 依赖列表
├── setup_env.bat          # Windows 环境设置脚本
├── setup_env.sh           # Linux/Mac 环境设置脚本
├── deploy.bat             # Windows 一键部署脚本
└── deploy.sh              # Linux/Mac 一键部署脚本
```

## 常见问题

### Q: 提示 "python 不是内部或外部命令"？

A: 请确保已安装 Python，并使用完整路径或添加到 PATH 环境变量。

### Q: 虚拟环境已存在，但依赖未安装？

A: 可以手动激活虚拟环境后运行：
```bash
pip install -r deploy_requirements.txt
```

### Q: 如何重新创建虚拟环境？

A: 删除 `venv` 目录后重新运行 `setup_env.bat` 或 `setup_env.sh`：
```bash
# Windows
rmdir /s venv
setup_env.bat

# Linux/Mac
rm -rf venv
./setup_env.sh
```

### Q: 可以使用 Python 3.x 吗？

A: 可以，脚本会自动使用 `python` 或 `python3`。如果系统中只有 `python3`，可以修改脚本中的命令。

## 依赖说明

部署脚本仅需要以下依赖：

- **paramiko** (>=2.12.0): 用于SFTP连接和文件传输

这些依赖都是轻量级的，不会影响系统Python环境。
